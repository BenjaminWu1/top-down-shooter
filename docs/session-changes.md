> Imported by `../CLAUDE.md` via `@docs/session-changes.md`. Part of the project guidance — keep in sync with the code.

These changes are recent enough to be worth recording so future passes don't unintentionally regress them:

- **Passive EQUIPPING moved from the SHOP to the CHARACTER SELECT screen (the SHOP now only buys/upgrades).** Per request, passives are chosen where you start every run so you see their progress each level. New module state `passiveMenuSlot` + helpers `passiveSlotRect(i)` / `passiveMenuOptions()` / `passiveMenuRects(slot)` / `setPassiveSlot(i,id)` (ordered, dedup'd, capped at `maxPassiveSlots()`). `charCardRect` slimmed (172→160 h, y 56→52) to free a band below the cards; `drawCharacterSelectPassives()` renders a centered row of **`maxPassiveSlots()` slot boxes** (each shows the equipped passive + **level + a mini progress bar**, or `+ EMPTY`) under a `PASSIVES n/max` header, plus a **click-to-open dropdown** (`passiveMenuRects`, stacks upward over the cards) listing `— EMPTY —` + every owned passive. `handleCharacterSelect` resolves a dropdown-option click → `setPassiveSlot` (and a click outside just closes the menu, never proceeding) **before** the character-card loop; `passiveMenuSlot` resets on entering/leaving the screen. (Supersedes the "PASSIVES tab equip toggle" detail in the entry below.)
